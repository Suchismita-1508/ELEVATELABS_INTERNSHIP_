# 📊 TASK_1 – Data Cleaning & Preprocessing

## 🎯 Objective
The objective of this task was to clean and preprocess a customer dataset by handling missing values, removing duplicate records, and transforming the data into a structured format suitable for analysis.

## 🛠️ Tools & Technologies
- Python
- Pandas
- Jupyter Notebook

## 📂 Dataset
- Customer Personality Analysis Dataset

## ✅ Tasks Performed
- Loaded the dataset using Pandas.
- Inspected data types and checked for missing values.
- Removed unnecessary columns.
- Filled missing values in the **Profession** column with **"Unknown"**.
- Removed duplicate records.
- Applied Label Encoding to categorical columns.
- Exported the cleaned dataset as **Cleaned_Customers.csv**.

## 📁 Files Included
- Customers.csv
- Cleaned_Customers.csv
- DataCleaning_.ipynb
- README.md

## 📌 Outcome
Successfully prepared a clean and reliable dataset for analysis by improving data quality, handling inconsistencies, and applying essential preprocessing techniques.
